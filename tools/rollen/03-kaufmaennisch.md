# Steckbrief Rolle Kaufmännisch

- Rolle: Kaufmännische Zuarbeit
- Name: nicht besetzt, keine erfundene Person
- Tut: Unterlagenmappe zur Kanzlei, Rechnung, Mahnung, offene Posten
- Tut nicht: Steuererklärung, Buchhaltung als Ersatz der Kanzlei, Abnahme
- Berichtsweg: an den Inhaber
- Sichtbar nach außen: nein, bis eine echte Kraft benannt ist
- Status: geplant, frei
