# Gensingen Consulting - Hauptquartier

Dieses Repository dient als zentrales Nervensystem für den operativen Betrieb von Gensingen Consulting. Es enthält alle internen Prozesse, Kundendaten, Werkzeuge und die Wissensbasis, die für die Ausführung unserer Mandate notwendig sind.

## Struktur

- **/mandates**: Kundenakten, nach Mandat getrennt.
- **/internal**: Interne Prozesse (SOPs) und Vorlagen.
- **/docs**: Zentrale Wissensdatenbank (Unternehmensleitbild, Geschäftsmodell etc.).
- **/tools**: Wiederverwendbare Skripte und Automatisierungs-Werkzeuge.
- `todo.md`: Das zentrale Aufgaben-Board zur Steuerung der Mitarbeiter-Agenten.
