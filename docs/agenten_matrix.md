# Gensingen Consulting: Erweiterte Agenten-Fähigkeiten-Matrix

**Datum der Erstellung:** 07.10.2026
**Letzte Aktualisierung:** Jetzt

Dieses Dokument dient als zentrale Referenz für alle Agenten und Sub-Agenten im Gensingen Consulting KI-System. Es listet detailliert ihre Rollen, die spezifischen Aktionen, die sie ausführen können, die dafür genutzten Werkzeuge und die zugehörigen Wissensquellen auf. Die Matrix wird kontinuierlich erweitert, um neue Fähigkeiten und Agenten widerzuspiegeln.

## Legende
*   **Agenten-Rolle / Komponente:** Der Name oder die Funktion des Agenten/Systems.
*   **Zweck / Beschreibung:** Eine kurze Erklärung der Hauptaufgabe.
*   **Spezifische Fähigkeit / Aktion:** Die kleinste, atomare Handlung, die der Agent ausführen kann.
*   **Werkzeug / Befehl:** Das primäre Werkzeug oder der Befehl, der zur Ausführung der Aktion genutzt wird.
*   **Parameter / Argumente:** Die typischen Parameter, die für diesen Befehl/dieses Werkzeug relevant sind.
*   **Erklärung / Ziel der Aktion:** Der genaue Zweck oder das erwartete Ergebnis der Ausführung.
*   **Wissensquellen (Dokumente/Datenbanken):** Externe oder interne Informationen, auf die der Agent zugreift oder die er nutzt.
*   **Status:** Der aktuelle Entwicklungsstand der Fähigkeit (z.B. Aktiv, Implementiert, Geplant, Zukünftig).
